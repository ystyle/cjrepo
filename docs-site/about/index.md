# 关于 CJRepo

CJRepo 是**仓颉语言包私有仓库服务**，兼容 cjpm 的发布/下载/索引协议。

## 功能特性

- 包发布与下载（兼容 cjpm 二进制协议）
- 索引查询服务
- 用户与组织管理
- 团队权限控制
- 上游源代理与同步
- 发布计划（依赖解析 + 批量发布 + 实时跟踪）
- 管理后台（Vue 3 + Element Plus）
- 完整文档站点

## 技术栈

| 层 | 技术 |
|---|------|
| 后端 | Go + Fiber + XORM |
| 前端 | Vue 3 + Element Plus + Pinia |
| 文档 | VitePress |
| 数据库 | SQLite |
| 协议 | cjpm 二进制协议 |
| 认证 | JWT + Token |
| 部署 | Docker / 二进制发布 |
