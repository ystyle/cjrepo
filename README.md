# CJRepo - 仓颉私有仓

兼容 cjpm 的仓颉包私有仓库服务，支持包的发布、下载和索引查询。

## 快速开始

```bash
git clone https://github.com/ystyle/cjrepo.git
cd cjrepo
docker-compose up -d
```

访问 http://localhost:8060/admin 进入管理后台。

## 文档

完整文档请访问 [GitHub Pages](https://ystyle.github.io/cjrepo/docs/) 或在本地启动后访问 `/docs`。

## 系统要求

仓颉 SDK **v1.1.0** 或更高版本（[下载地址](https://cangjie-lang.cn/download)）。
