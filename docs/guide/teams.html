团队权限 ​

团队是 CJRepo 的权限管理核心。权限采用 双路径模型。

权限级别 ​

级别说明
read可下载包和查看索引
write可发布新版本
overwrite可覆盖已存在的版本

双路径模型 ​

路径 1：个人发布（无组织包） ​

任意有效 Token 即可发布无组织包，首次发布者自动成为 publisher：

操作规则
发布新包✅ 任意有效 Token 即可
发布新版本✅ publisher 自动获得 write 权限
覆盖版本❌ 需团队 overwrite 权限

路径 2：团队管理 ​

团队通过组织关联或包关联获得权限控制：

操作规则
发布新包（有组织）❌ 必须有团队关联了该组织
发布新版本✅ 团队关联了该 org/pkg 且权限 >= write
覆盖版本✅ 团队关联了该 org/pkg 且权限 >= overwrite

组织关联 ​

搜索组织并关联到团队，团队获得该组织下所有包的管理权：

包关联 ​

搜索包并关联到团队（支持 org::keyword 格式），团队获得该包的独立管理权。权限继承自团队默认级别：

管理团队 ​

  1. 进入管理后台 → 团队管理
  2. 创建团队，设置默认权限（read/write/overwrite）
  3. 添加成员（搜索用户）
  4. 关联组织——团队获得该组织下所有包的管理权
  5. 关联具体包——团队获得特定包的管理权（权限继承自团队默认级别）
