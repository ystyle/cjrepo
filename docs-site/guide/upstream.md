# 上游代理

CJRepo 支持配置上游代理源，当本地没有请求的包时，自动从上游源拉取并缓存。

## 配置上游

![上游管理](/assets/admin_upstream.png)

在管理后台的「上游管理」页面，可以：

- **添加上游源** — 设置名称、URL、认证 Token
- **启用/禁用** — 临时开关上游源
- **缓存 TTL** — 设置缓存过期时间（秒）
- **测试连接** — 验证上游源是否可达
- **清除缓存** — 手动清理该上游的缓存数据

## 同步机制

- 下载请求优先查本地存储
- 本地不存在时依次查询启用的上游源
- 命中上游后缓存到本地，下次直接命中
- 缓存根据 TTL 自动失效
